# City Summary

Домашнее задание ко второму уроку. Программа показывает погоду в городе и курс выбранной валюты к рублю.

Погода берётся из Open-Meteo, курс — из Frankfurter. Ключи API не нужны.

## Установка

Нужен Python 3.12. Из папки проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

В Windows окружение активируется командой `.venv\Scripts\Activate.ps1`.

## Запуск

```bash
python main.py --city Moscow
python main.py --city Moscow --currency EUR
python main.py --city Москва --json
```

По умолчанию используется USD. Названия из нескольких слов нужно брать в кавычки: `--city "New York"`.
Если найдено несколько городов, выбирается первый результат поиска.

Пример вывода (значения зависят от текущей погоды и курса):

```text
Город: Moscow
Погода: -3.2°C, ясно
Тёплая одежда: да
USD→RUB: 92.15
Дорогой курс: нет
```

Если температура ниже 0, включается флаг `warm_clothes`. Если курс больше 100 рублей — `expensive`. Флаг `--json` выводит всю сводку в JSON.

## Как устроен проект

- `main.py` — аргументы командной строки и вывод результата.
- `clients/` — запросы к API, повторы и проверка ответов.
- `processing/` — сборка сводки и правила для температуры и курса.
- `tests/` — проверки без обращения к настоящим API.

Для каждого запроса установлен timeout 10 секунд. При сбое соединения, тайм-ауте, HTTP 500/502/503/504 или 429 запрос повторяется ещё два раза. При 429 учитывается числовой `Retry-After`.

Ошибки выводятся в stderr. Коды завершения:

- `0` — сводка получена;
- `2` — неверные аргументы;
- `3` — город или валюта не найдены;
- `4` — сервис недоступен или вернул некорректные данные.
